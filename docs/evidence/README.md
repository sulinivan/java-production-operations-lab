# Portfolio Evidence (§45)

Каждый артефакт сопровождается записью формата:

```text
Problem      — что должно было быть доказано/решено
Action       — что сделали
Expected     — ожидаемый результат
Actual       — фактический результат (команда + вывод)
Evidence     — скриншот / лог / ссылка
```
